# mylib


Concept:
A person wants to open a book club in his local area. He request the super admin for access. Super admin creates a club and makes him a admin. Then, as a

- Super admin: One who creates new Book clubs and club admins.

- Club admin: He can add/remove club members.

- Club members: 1) They can add books in club pool. 2) Borrow books to read 3) Can provide social rating to fellow members.

NOte: 
- Each book club has their seperate book pools. i.e. no members can access another club
- Can be accessed through mobile app.
- This app is a ocean and each book club is an island.

Mission:
- Saves costs on infrastructure to build book library.
- Robust system to track book, borrower and owner with best communication system.
- Encourage community sharing and reading physical books among youth.
